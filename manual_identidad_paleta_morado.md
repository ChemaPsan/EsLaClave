# Manual de Identidad Visual – Paleta Principal

## Concepto General
La identidad visual se construirá sobre una gama de colores morados, violetas y magentas con apariencia moderna, tecnológica y premium. El morado será el color predominante de marca.

Para comunicaciones formales, documentos serios y entornos corporativos se utilizarán blanco y negro como base principal.

## Distribución Recomendada

### 70% Morado predominante
- Botones principales
- Encabezados
- Elementos visuales de marca
- Gradientes
- Interfaces destacadas

### 20% Blanco / Negro
- Textos principales
- Fondos sobrios
- Contratos / PDFs / módulos serios
- Dashboards corporativos

### 10% Rosa brillante
- Llamados a la acción (CTA)
- Alertas positivas
- Detalles premium
- Indicadores especiales

## Recomendaciones de Uso

### Sí usar
- Gradientes elegantes
- Contraste alto en botones
- Fondos oscuros con texto blanco
- Morado como identificador principal

### Evitar
- Saturar toda la interfaz con rosa
- Usar demasiados tonos sin jerarquía
- Fondos claros con textos magenta de baja legibilidad
- Mezclar colores ajenos a la gama principal sin criterio
